## JOB RECOMMENDER SYSTEM

## Brief Overview

This is a web application that is designed to match job seekers with suitable job opportunities based on their skills, preferences, and past experiences.

## Project Setup

- DATABASE FILE: job_recommender_system.sql
- DATABASE NAME: job_recommender_system
- DATABASE TABLES:
  - admin
  - counties
  - employment_type
  - job_applictions
  - job_industries
  - job_levels
  - job_titles
  - posted_jobs
  - skills
  - users

- Download xampp from <https://www.apachefriends.org/download.html> if you haven't. After installation, start the servers, and go to phpmyadmin. Create a database and name it "petition_platform", thereafter import the "job_recommender_system.sql" file into your new database

- Upload all the files in the opt/lampp/htdocs folder and run the program using the URL: "localhost/Job_Recommender_System/home"
